# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/). До 1.0 схема событий, состав правил и форматы
могут меняться.

## [Unreleased]

### Добавлено
- Схема событий 1 (JSON Schema) в полях ECS с расширением `scii.*`: решения гейта и состояния
  свидетельств, отчёты устройств о вводе в эксплуатацию, установке, отказе и командах управления;
  шаблон индекса OpenSearch и Elasticsearch, построенный из схемы.
- Выгрузка `python -m sciitel export` из каталога стенда cps-update-lab: проверка подписи отчётов
  ключом устройства, сверка установленных образов с журналом гейта, изменение номера версии;
  сверка и изменение версии — только для отчётов с действительной подписью. Команды `validate`,
  `compare` (без изменчивых полей), `index-template`, `bulk`.
- 19 файлов правил Sigma: 12 по отчётам устройств, 5 по решениям гейта, корреляции «гейт отверг —
  устройство установило» и «подбор пароля управления»; конвейер полей pySigma.
- Наборы событий `cpslab-0.1.0` (33 прогона сценариев стенда, 8 решений гейта) и `cases-0.1.0`
  (дополнительные случаи C1–C9 `labcases/cases.py`) с сырыми выходами стенда и происхождением;
  7 синтетических событий (отказ STATE и границы окна корреляции).
- Стенд правил на SQL бэкенда pySigma для SQLite с корреляциями по спецификации Sigma, матрица
  обнаружения и её сверка с каталогом сценариев стенда, отчётами scii-gate и сырыми отчётами
  устройств; мутационная проверка 53 значений условий.
- Проверки правил: 31 валидатор pySigma с MITRE ATT&CK 20.1 (Enterprise и ICS), поля и значения
  условий по схеме, согласованность техник и тактик.
- Запросы OpenSearch, Elasticsearch (Lucene, EQL, ES|QL) и Splunk; исполнение в OpenSearch 3.8.0 и
  Elasticsearch 9.5.5 в CI с перечнем известных расхождений и проверенными правками для дефектов
  бэкенда EQL.
- CI: тесты на Python 3.11 и 3.13, движки SIEM, пересборка наборов из закреплённых коммитов
  cps-update-lab, scii-gate и scii-verify, actionlint.
- Документация: схема, правила, матрица обнаружения, работа с SIEM; README со схемами Mermaid.
- Набор `ardupilot-0.1.0`: решения гейта по 16 сценариям ПМИ стенда ArduPilot из scii-gate
  (Copter-4.5.7, плата CubeOrange, официальный прогон 30.10.2026), 288 событий. `raw/` — файлы
  прогона без изменений и `packages.json` с платой, версией и SHA-256 пакета каждого комплекта.
  Сборка `python -m tools.ardupilot raw`, перепроверка `python -m tools.ardupilot rerun`: решения
  scii-gate по 16 комплектам заново, сверка отчётов с прогоном.
- Выгрузка `python -m sciitel export-ardupilot` из файлов прогона стенда ArduPilot; `compare
  --ignore` для полей, которые различаются по известной причине (версия гейта при перепроверке).
- Ожидания по набору ArduPilot из плана испытаний scii-gate (SHA-256 плана записан до прогона);
  тесты границ: скомпрометированный сборочный агент без контрольной пересборки (A5b) неотличим от
  штатного B3, вето подлинному пакету при необновлённой после смены ключа политике (B5a) —
  ложное срабатывание, указанное в правиле вето.
- CI: задание `ardupilot` — scii-gate на закреплённом коммите заново принимает решения по 16
  комплектам (Python 3.11, pymonocypher 3.1.3.2, cosign), отчёты и выгрузка сверяются с набором.
